# 🎓 ISIMM L2 INFO Score Calculator

A React application that calculates semester and annual grades for ISIMM Computer Science students.

## 🚀 Features
- Calculate subject grades
- Supports MX & CC systems
- Semester average calculation
- Mention system (Passable, Bien, etc.)
- Local storage support

## 🛠️ Tech Stack
- React JS
- CSS3
- Vite
